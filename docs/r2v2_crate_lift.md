# R2V2 双手插孔与抬箱台架实验

本实验只验证双手与箱把手的接触、握持和同步抬升，不运行全身 Reach 策略，
不代表机器人已经具备负载平衡、双臂可达性或实机提箱能力。原有抓瓶 75° 手型和
全身任务不变，箱内暂无瓶子。

冻结双臂 Reach 的真实整机接入是独立实验，见
[全身双臂 Reach 抬箱实验](r2v2_crate_reach.md)；台架通过不代表该全身实验通过。

## 物理与控制边界

- 空箱沿用 `deploy_mujoco/config/r2v2_crate.yaml`：左右宽 360 × 前后深 240 × 高 160 mm、0.4 kg，
  两侧真实开孔 120 × 55 mm，上梁参与真实碰撞；箱体只有一个自由关节。
- 手部保留原模型的质量、惯量、碰撞、关节限位、12 路执行器与 10 个 mimic 约束。
  手指轨迹 100 Hz，限力矩控制及接触积分 1 kHz；四指每路最大 0.35 N·m。
- 双腕由两个**外部支撑夹具**带动，不模拟肩肘或机器人的力矩能力。
  每只真实手腕是独立动力学 freejoint 刚体，通过仅作用于手腕的 weld 跟随 mocap 目标。
  这两个 wrist weld 是台架驱动，不连接箱体；箱子没有 weld、吸附、外加辅助力，
  运行中不重置箱体位置。台面固定。
- 不将真实手直接挂在 mocap 父节点下：MuJoCo 会把该节点视作零速度固定体，
  接触中缺少整体腕运动的速度项。采用动态腕跟随目标的结构，使腕速度参与接触求解。
  参考 [MuJoCo 3.3.7 MoCap bodies](https://mujoco.readthedocs.io/en/3.3.7/modeling.html#mocap-bodies)。
  首轮旧驱动探索记录仅供诊断，不作为新动态腕方案的通过证据。

## 顺序与通过条件

`READY → INSERT → INSERT_SETTLE → CLOSE → TRIAL_LIFT → TRIAL_HOLD → LIFT → HOLD → COMPLETE`

1. 两手掌心朝上、左右镜像，从箱孔外沿直线同步插入。拇指保持 75°，四指张开。
   插入深度指最短张开小指越过普通侧壁内面的距离，不是闭合后指尖深度。
2. 每侧下发一次 `1`，四指使用本实验独立的闭合角。该姿态是**四指勾托**，
   不是抓瓶时的拇指对捏；原有抓瓶配置不被覆盖。
   当前 60 mm 深插方案在闭合的 2.5 s 内，双腕以五次平滑曲线同步上移 17.5 mm
   贴合横梁；水平插入深度不变。插入阶段本身不做这个上移，避免先顶歪箱子。
3. 确认两侧实际指部接触持续 0.3 s 后，双腕试提 2 cm。箱底离台至少 8 mm、
   台面不再承重、两侧手指各自对上梁的世界 Z 向力至少 0.2 N，且每只整手的净
   向上作用力至少 0.2 N、姿态和滑移合格，
   持续 0.3 s，才进入完整抬升。
4. 贴合闭合后，双腕试提及正式抬升累计上移 10 cm，保持 3 s。加上贴合行程，
   从插入位姿到最后腕目标共上移 117.5 mm。保持期间箱底必须一直离台至少 8 cm，
   倾斜不超过 8°，两侧均承重，箱体相对任一实际手腕的平移变化小于 15 mm。
   相对位移基准取试提前，包含握持受载的就位变化，不在中途重置以消除误差。
5. 最后保持握持，不自动松手。任何失败进入 `FAILED` 并终止本次仿真，
   不继续移动、不瞬移箱体、不在空中自动张手。

此外检查手部限位、mimic 误差、数值警告、手箱/自碰撞穿透、手台/手地碰撞、
箱体落地、腕部位置跟踪 3 mm 和方向跟踪 3°。量测及状态机运行在 100 Hz，
日志中的峰值是该采样率下的观测峰值，不是连续时间最大值。

## 运行与输出

在仓库根目录执行，输出目录必须为空：

```bash
MUJOCO_GL=egl .venv-r2v2/bin/python deploy_mujoco/r2v2_crate_lift.py \
  --video --output artifacts/r2v2_crate_lift/my_run
```

默认读取 `deploy_mujoco/config/r2v2_crate_lift.yaml`。可用 `--config` 选择独立 YAML，
或用 `--closed-curl 0.80` 覆盖四指目标弯曲角，单位 rad。`--no-grasp` 保持张手并禁用闭合贴合上移，
用来检验无实际闭合接触时状态机是否拒绝试提；这个对照**不证明**强制抬起张开的
手指就绝不可能从下方托住横梁。

输出：双固定机位 `crate_lift.mp4`、各阶段截图、`transitions.json`、
100 Hz `trace.json`（箱体轨迹、接触力、手腕实际/目标、指关节/参考/力矩）、
`report.json`（配置、源文件哈希、判据、结果、峰值及完整保持样本）。
视频显示的是整手（四指、拇指、手掌）对箱体的合成世界 Z 向净力，
不是接触法向力之和、内部夹紧力或 `CLOSED` 状态。
程序只有全部通过且录制无错误才以 0 退出；失败保留诊断并以 1 退出。

主要实现：`common/r2v2_crate_lift_scene.py`（台架场景）、
`common/r2v2_crate_lift.py`（独立状态机）、
`common/r2v2_crate_lift_metrics.py`（只读接触量测）、
`deploy_mujoco/r2v2_crate_lift.py`（渲染入口）。

## 2026-09-09 初版小箱、30 mm 插入基线结果

当时方案为：箱体前后 200 × 左右 280 × 高 100 mm，插入 30 mm；
四指闭合目标 0.30 rad（约 17.2°），由限矩接触决定
实际关节位置；2 s 试提 20 mm，4 s 再上移 80 mm，保持 3 s。没有放宽原抓取判据。
腕支架 weld 使用 `solref=[0.005,1]`、`solimp=[0.95,0.99,0.001]`、
`torquescale=1`；这些是台架夹持参数，不是机器人腕电机能力。

`artifacts/r2v2_crate_lift/dynamic_wrists_final/` 保存正式视频与完整日志，
全流程 16.16 s，视频 30 fps、1280×720、486 帧。

| 项目 | 实测值 |
| --- | --- |
| 最终箱底最下点离台高度 | 87.92 mm |
| 保持期间最低离台高度 | 87.92 mm |
| 最终倾斜 / 全流程倾斜峰值 | 3.47° / 3.86° |
| 相对实际手腕平移变化峰值 | 6.85 mm |
| 最终左右四指对上梁的向上作用力 | 1.9615 / 1.9625 N |
| 最终台面对箱体的竖直作用力 | 0 N |
| 手箱接触穿透峰值 | 0.184 mm |
| 手指执行器力矩峰值 | 0.1865 N·m，未达到 0.35 N·m 上限 |
| 腕支架位置 / 朝向跟踪误差峰值 | 0.490 mm / 0.079° |
| 有效保持时间 | 3.000 s |

正式录制与另外两次同初始条件的无视频复跑均通过，结果一致；后两次摘要为
`artifacts/r2v2_crate_lift/dynamic_wrists_repeat_2.json` / `dynamic_wrists_repeat_3.json`。
这是确定性复现与“渲染不影响物理”的检查，不是随机扰动鲁棒性或整机负载验收。

`dynamic_wrists_no_grasp/` 为保持张手的门控对照：到 10.02 s 因没有建立双侧
有效闭合接触而停止，未进入试提；对照按预期拒绝完成。

调参发现，在相同动态腕驱动下，0.45 rad 闭合目标会令箱体试提倾斜超过 8°门槛，
因此不采用；0.30 rad 的原速和较慢两组轨迹均能通过。更大的闭合角并不等于
更稳的勾握。后续接入全身策略时，需要重新验证双手可达、负载平衡、目标误差和
接近过程；不得直接用这个台架结果宣称整机可提箱。

## 当前：大箱、60 mm 深插、较充分闭合

按用户要求改为左右宽 360 × 前后深 240 × 高 160 mm，两孔仍是 120 × 55 mm。
孔仍位于顶部 20 mm 横梁下方，Z 范围变为 85–140 mm。空箱总质量继续设为
0.4 kg，不按体积增长自动加重；质量在新几何上重新分配，惯量随之重新计算。

双手张开插入深度 60 mm；四指闭合目标从 0.30 调至 **0.80 rad（45.8°）**。
原有 0.35 N·m 四指限矩、真实关节限位、碰撞与成功判据均保留，额外检查整手
净承重，防止误把相互抵消的指部/掌部夹紧力当作抬升负载。

较深插入后，仅增大闭合目标仍可能空握或压住横梁。最后采用
`closure_seating_m: 0.0175`，在完成无碰撞插入后，闭合时缓慢向上贴合横梁。
不是以更高腕姿水平硬插；后者虽然某些参数能抬起，但插入倾斜曾达约 14°，未采用。
`closure_seating_m: 0` 可关闭该动作，范围限制为 0–30 mm。

正式视频与轨迹：`artifacts/r2v2_crate_lift/large_crate_60mm_tight_final/`。
全流程 16.16 s，插入及插入停稳阶段没有检测到手箱接触，箱体未被顶斜。

| 相对实际腕平移变化峰值 / 最终值 | 7.930 / 7.204 mm |

| 连续有效保持时间 | 3.000 s |

正式录制和两次同初始条件复跑均通过；这仍只是确定性台架复现，不是扰动鲁棒性
