# R2V2 单手台面抓取展示

这是 `r2v2-fsm` 分支的**独立仿真展示入口**，不接实机、不新增训练。
使用新完整机器人、`model_12000.pt` 对应双臂 Reach ONNX，以及原有 75° 手型二值控制器。

用户在严格空载 Reach 精度测试失败后，明确要求先展示台面任务。
因此本入口保留并显示左腕误差，但不以 5 mm / 3° 阻断运动阶段；
**它不代表原严格兼容性测试通过**，也不是三次成功率/鲁棒性验收。
原验证入口和已确认固定手腕抓取基线均未修改。

## 运行入口

在本仓库根目录执行：

```bash
uv pip install --python .venv-r2v2/bin/python -r requirements-r2v2-reach-sim.txt

# 原始训练/部署推理对照仍必须通过；已有同版本报告可复用。
.venv-r2v2/bin/python tools/verify_r2v2_reach_policy.py

.venv-r2v2/bin/python deploy_mujoco/r2v2_tabletop_demo.py \
  --parity-report artifacts/r2v2_reach/parity_12000/report.json \
  --video
```

支持 `--config`、`--output`；输出目录必须为空。未指定目录时写入
`artifacts/r2v2_tabletop_demo/时间戳/`。默认无显示器时使用 EGL。
不传 `--video` 时仍保存各阶段截图与完整物理日志。
退出码 0 只表示本次演示完成；1 表示失败或运行异常。

| 文件 | 职责 |
| --- | --- |
| `deploy_mujoco/config/r2v2_tabletop_demo.yaml` | 台面布局、接近/抬升/搬运/撤离距离、时间和物理判据 |
| `common/r2v2_tabletop_scene.py` | 固定桌面、自由圆柱、物体位姿/接触力测量 |
| `common/r2v2_tabletop_demo.py` | 场景预热初始化、抓取搬运状态机、失败保护和记录 |
| `deploy_mujoco/r2v2_tabletop_demo.py` | 双视角录像、目标标记、CLI 和输出文件 |

权重路径仍在 `deploy_mujoco/config/r2v2_reach.yaml`。完整策略接口约定见
[Reach 部署说明](r2v2_reach_deployment.md)。

## 场景与控制

- 左手执行任务，右手锁定预热站稳时的世界末端位姿；不锁定右臂关节。
  右腕保持的 2 cm / 5° 门槛仍保留，持续超出 0.3 s 则停止。
- 圆柱直径 4 cm、高 12 cm、质量 100 g，真实自由关节。
  手型、限力矩、接触参数沿用固定手腕基线，不改变新机器人关节限位/惯量/碰撞。
- 身体策略 50 Hz，独立手部参考 100 Hz，两者 PD 与接触仿真 1 kHz。
  每段只设置一次世界终点，保留训练速度条件，不把手指接入 RL。
- 新机器人默认垂臂位置会穿过高台面，所以先在空场景自由站稳、进入待机，
  再在**场景初始化**时按关节和执行器名字复制机器人状态，续接策略历史与手部轨迹。
  视频从已站稳且无初始穿插的场景开始；运行中不重置机器人/圆柱、不移动桌面。
- 桌面为站稳后腰部高度加 10 cm，本次约 1.1109 m。
  台面范围 `x=[0.36,0.75]、y=[-0.10,0.42] m`，厚 4 cm；
  圆柱初始 `x=.40,y=.20`，目标 `x=.40,y=.10`。
  圆柱底部距近边有 2 cm 支撑余量，给竖直落放时俯仰的腕部留出空间。

本展示场景单独开启 `multiccd` 多点接触检测，不改碰撞几何或物体摩擦模型。
原 MuJoCo 3.3.7 配置的圆柱—箱形台面只有一个接触点；从实际受扰物体状态移除
机器人后仍可复现持续晃动。补全多点接触后，自由圆柱可独立落稳。
这个选项用于改善平面接触的单点近似问题，见
[MuJoCo 3.3.7 官方说明](https://mujoco.readthedocs.io/en/3.3.7/XMLreference.html#option-flag-multiccd)。
它影响本场景的凸体接触检测，因此整条抓取流程重新回归；原固定手腕基线未开启此改动。

## 运动与真实抓取判定

流程为：待机 → 向外让开 → 侧向预接近 → 分段靠拢 → 闭合 → 试提确认 →
抬升 → 向中线搬运 → 调整圆柱竖直 → 分段下降 → 触台 → 张开 → 撤离 → 稳定完成。

圆柱位姿读取仿真真值，初始腕柱关系为 `[.145,-.035,0]` m、单位四元数。
先求 `T_world_wrist = T_world_cylinder @ inverse(T_wrist_cylinder)`，
再乘标定的 `T_wrist_tcp`，不能把圆柱中心直接送给 Reach。

左手掌面朝局部 **−Y**；手指纵向 +X 不是接近法向。
原先从 −X 后退再靠近会让张开四指扫入圆柱，故增加向外对齐点，
再到局部 +Y 的 5 cm 预接近点，最后沿 −Y 每 1 cm 分段进入。
运动切换检查参考已到终点、实际腕速度低且持续停稳，而末端误差仅记录。

`CLOSED`/手指参考完成不等于抓住。闭合至少 2.5 s，拇指及对侧手指都有有效接触，
再试提 2 cm；底部确实离台超过 8 mm、没有台面支撑、对指接触有效，
且腕柱相对平移/姿态稳定持续 0.3 s，才确认抓取。

确认后保存实测腕柱关系，目标抬升 8 cm、向中线移动 10 cm。
搬运中持续检查接触、滑移和身体稳定；提前掉回台面也不能作为搬运成功。
落放前用实测关系反算让**圆柱竖直**的手腕姿态，不直接复用初始腕姿态。
接近桌面后以 3 mm 步长有界探测支撑；实际触台停稳后才张开，
停止追加下探目标。最终要求物体在目标 2 cm 范围、倾斜小于 10°、
台面支撑且手指没有有效接触，持续静止至少 1 s。
撤离沿当时手腕局部 −X 后退 4 cm，同时 +Y 外撤 12 cm，为实际轨迹偏差留出拇指余量。

所有阶段有 10 s 超时；跌倒、非脚着地、机器人碰桌、明显自穿插、数值异常、
失握/滑落均停止。失败路径不会自动在空中张手，不关闭碰撞，不施加辅助外力。

### 文件内容

- `demo.mp4`：全身及手物近景；绿色圆盘只存在于渲染层，表示放置目标，不参与碰撞。
- `report.json`：模式标记、完成/失败阶段、参数及代码哈希、腕部误差、物体终点/倾角、
  滑移、离台高度、对指接触比例、身体安全指标。
- `trace.json`：100 Hz 的双手目标/参考/实测位姿、身体与手部关节/参考/力矩、物体
  世界/相对位姿、接触力及支撑状态。状态切换时同步保存。
- `transitions.json`、逐阶段 PNG、`initial.png`、`final.png`：状态时序与关键帧。

大体积结果保存在忽略的 `artifacts/`，不随 Git 保存。此展示只验证一个固定布局，
不代表任意物体尺寸/扰动均可成功。改布局时仍需重验撤离路径、桌边余量和受扰圆柱
接触稳定性，不能只看最终一张截图或控制器的状态标签。
