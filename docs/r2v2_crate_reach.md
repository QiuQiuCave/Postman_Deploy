# R2V2 全身双臂 Reach 抬箱实验

本入口把已验证的双手台架目标接到新完整 R2V2 的冻结双臂 Reach 策略上。
**当前实际结果：孔外准备位未到达，未插入、未闭合、未抬箱。**
不能用台架通过或本入口的单元测试通过代替全身抬箱成功。

## 基线与控制边界

原台架及箱体已在 `r2v2-fsm` 的 `bfc4888` 提交，入口和参数保留不变，见
[双手台架实验](r2v2_crate_lift.md)。本次全身实验新增独立入口和配置：

- `common/r2v2_crate_reach_scene.py`：新完整机器人、固定台面、自由箱体；
- `common/r2v2_crate_reach.py`：冻结策略接入、世界坐标目标、状态机和安全检查；
- `deploy_mujoco/config/r2v2_crate_reach.yaml`：摆放、准备位/插入位门槛；
- `deploy_mujoco/r2v2_crate_reach.py`：运行、双机位视频及指标输出；
- `tests/test_r2v2_crate_reach.py`：模型不变性、坐标、通道分离、门控等回归测试。

真实整机自由基座、惯量、关节限位、碰撞和执行器全部保留。模型有 28 路身体、
12 路手部执行器；只有原来的 10 个手指 mimic 等式，没有 mocap、手腕 freejoint、
手腕支撑 weld、箱体 weld、IK、辅助力或运行中的姿态重置。
`nq=64, nv=62, nu=40, neq=10, nmocap=0`。

身体使用 `deploy_mujoco/config/r2v2_reach.yaml` 指定的 `model_12000.pt` 对应 ONNX，
沿用已做数值对照的观测、历史、归一化和动作映射，不改策略代码或权重。
运行前检查数值对照报告通过，以及 checkpoint、ONNX 和部署适配器哈希匹配。
这是复用并核验既有接口对照证据，不声称本次重新运行了训练环境数值对照。
身体策略 50 Hz、手指轨迹 100 Hz、力矩控制和接触仿真 1 kHz；
状态机、安全判定和日志为 100 Hz，日志峰值不等于连续时间峰值。

箱体沿用左右宽 360 × 前后深 240 × 高 160 mm、空箱 0.4 kg、双孔 120 × 55 mm。
手型仍为 75° 拇指、张手插入 60 mm、四指闭合目标 0.80 rad、每路四指限矩 0.35 N·m。
闭合贴合上移 17.5 mm，然后试提 20 mm，完整抬升累计 100 mm，保持 3 s。

## 场景初始化和目标

先在无桌箱场景完成待机，到 `STANDING_CHECK` 后继续站立 2 s；本次总预热约 4.18 s。
这是每次实验的准备步骤，不是重新做一遍 20 s 整机验收。
随后一次性把机器人状态、策略历史和运动参考复制进带桌箱的新场景。
台面取预热后 `waist_pitch_link` 高度加 0.10 m，本次为 1.110919 m。

台面中心 XY 为 `[0.48, 0] m`，半尺寸 `[0.22, 0.35, 0.02] m`；
箱体中心 XY 为 `[0.48, 0] m`，轴向与世界坐标一致，初始箱底留 1 mm 间隙并自然落桌。
早期 `[0.43, 0] m` 摆放与已经张开的手相交，故在重置前将箱体移到 0.48 m。
没有在运行中移动箱子，也没有改变箱尺寸、孔位、摩擦、质量或插入深度。

目标标定直接复用台架的原始手碰撞几何和张手指尖深度。先计算世界手腕目标，
再使用固定手腕到策略 TCP 变换右乘，不能直接把箱中心或腕位置当成 TCP。

`T_world_tcp = T_world_wrist × T_wrist_tcp`

本次孔外手腕目标约为：

| 手腕 | 世界位置 XYZ / m | 世界 XYZ 欧拉角 RPY / ° |
| --- | --- | --- |
| 左 | `[0.480, +0.427988, 1.217407]` | `[-90, 0, -90]` |
| 右 | `[0.480, -0.427988, 1.217391]` | `[+90, 0, +90]` |

两掌朝上、手指向箱内。内部指令统一使用四元数，每次进入运动阶段各设置一次
`set_target_world`，不逐帧重启目标，也不清除策略历史。
沿用策略训练过的参考速度 0.25 m/s、0.8 rad/s 及加速度上限 0.8 m/s²、2 rad/s²。
因此目标几何和动作顺序与台架相同，**实际运动轨迹不再是台架指定的五次曲线**。

## 状态机与失败处理

`READY → PREALIGN → INSERT → INSERT_SETTLE → CLOSE → TRIAL_LIFT → TRIAL_HOLD → LIFT → HOLD → COMPLETE`

新增 PREALIGN 要求两个实际手腕同时到达孔外目标：位置误差 < 20 mm、姿态误差 < 10°、
线速度 < 25 mm/s，且策略参考运动完成，持续 0.3 s 才可插入。最多等 10 s。
INSERT_SETTLE 要求两个实际手腕误差 < 5 mm、3°，同样停稳后才发出闭合 `1`。
这不是因为误差稍大就假装抓住，而是在大幅错位时明确拒绝进入抓取阶段。

后续复用台架的真实双侧指接触、整手净向上承重、离台、箱体倾斜、相对腕滑移和
连续保持判据。`CLOSED` 或已发 `1` 都不能代表提箱成功。
真实机器人非脚触地、碰台、非手部碰箱、过深穿透、关节超限、身体失稳、
箱体过度倾斜或数值异常均停止。失败后不继续仿真或在空中自动张手。

## 复现

在仓库根目录运行，输出目录必须不存在或为空：

```bash
MUJOCO_GL=egl .venv-r2v2/bin/python deploy_mujoco/r2v2_crate_reach.py \
  --parity-report artifacts/r2v2_reach/parity_12000/report.json \
  --video --output artifacts/r2v2_crate_reach/my_run
```

可以通过 `--config` 指定独立 YAML。去掉 `--video` 仍保存截图与完整指标。
数值对照报告/策略文件是本机资产，不随代码提交；缺失或哈希失配时会拒绝启动。
成功返回 0；到位失败、安全停止或渲染异常返回 1，保留失败诊断。

输出包括 `full_body_crate.mp4`、阶段截图、`transitions.json`、`trace.json` 和
`report.json`。视频显示实际手部 0/1 命令；绿色/蓝色标记为左/右腕的世界目标。
日志包含真实双腕位姿与目标误差、身体动作/力矩、手指参考/实际/力矩、
箱体轨迹、接触、滑移，以及模型、权重、代码哈希。

## 2026-09-09 首次全身尝试

最终录制保存在 `artifacts/r2v2_crate_reach/fullbody_12000_final/`；
第一次同配置试运行保存在 `fullbody_12000_attempt/`。
仿真约 11.01 s，在 PREALIGN 等满 10 s 后失败；没有进入插入、闭合和抬升。
两次同配置运行的双腕最终误差完全一致；最终 MP4 为 1280×720、30 fps、332 帧，
11.067 s，已通过完整解码检查。源码哈希与报告一致，手部命令全程为 `0/0`。
新增 38 项测试通过；连同既有测试共 382 项通过。它们不代表物理抬箱验收通过。

| 项目 | 实测 |
| --- | --- |
| 左腕最终位置 / 姿态误差 | 148.59 mm / 47.54° |
| 右腕最终位置 / 姿态误差 | 274.13 mm / 67.99° |
| 左 / 右腕最终线速度 | 0.56 / 0.46 mm/s |
| 身体倾角采样峰值 | 6.19°，未跌倒 |
| 手箱穿透采样峰值 | 0.978 mm |
| 箱体倾斜采样峰值 | 0.443° |
| 真实抓握 / 抬升 | 未执行；箱体仍在台面上 |
| 辅助力 / 手腕夹具 / 数值警告 | 无 / 无 / 无 |

箱底最高间隙 1 mm 是初始重置间隙，不是抬起；未建立握持基准时，
报告中的滑移峰值 0 也不是握持稳定性的证据。

训练运行目录 `params/env.yaml` 的 `commands.reach` / `reach_right`
中，`workspace_orientation_ranges` 为 roll ±20°、pitch ±25°、yaw ±30°，
晚期 `reach_workspace` / `reach_right_workspace` curriculum 的 workspace_probability 为 1。
这些角度在采样时的本体 yaw 坐标系中定义，再转换成固定世界目标；并非始终限制在世界零朝向附近。
这里需要的双腕掌心朝上、向内大角度旋转明显超出该目标采样范围。
终点误差大且腕速已经接近零，是目前的实际阻碍；本次结果不能单独证明唯一原因是
训练分布，也没有排除新旧模型运动学、限位和几何可达性的影响。

接下来应先检查这种大角度姿态在真实新模型上是否可达，再讨论扩展双臂训练目标
和大角度姿态课程。当前未自动开启训练、添加 IK 修正、降低通过标准或换回旧身体。
只有先通过孔外姿态和插入位验证后，才能实测后续负载平衡与双侧握持。

## 2026-09-09 对照：26 cm 宽、台面降低 10 cm、箱子移近 10 cm

`r2v2_crate.yaml` 或原来的 36 cm 台架基线。

- 箱子左右宽 260 × 前后深 240 × 高 160 mm；孔仍为 120 × 55 mm。
- 台面相对腰部高度从 +100 mm 改成 0，实测台面高 1.010919 m，恰好降低 100 mm。
- 箱子中心 XY 从 `[0.48, 0]` 改成 `[0.38, 0] m`，即世界 -X 方向移近 100 mm。
- 台面水平位置及尺寸不变；箱子靠身体一侧的外缘 X=0.26 m，恰好与台面近侧边缘
  对齐，完整箱底仍受台面支撑。箱子以 1 mm 初始间隙自然落桌，没有运行中位姿重置。
