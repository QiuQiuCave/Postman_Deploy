# 下斜 + 水平偏航的复合插孔（2026-09-11）

## 本次只改 yaw

在此前手部台架基础上，保持双手指尖下斜20°、法向插入60 mm、闭合0.8 rad、
闭合上移贴合30 mm、随后抬升100 mm并保持2 s。箱26×24×16 cm、孔12×5.5 cm、
空箱0.4 kg、75°拇指、接触/力矩/安全判据全部不变。不运行或修改全身策略。

坐标以箱体为准：X前后、Y左右、Z向上。之前下斜对应绕箱X轴旋转；本次再绕箱Z轴叠加yaw。
两手镜像，不能给两只腕统一加相同符号的世界yaw。
脚本的`roll`专指绕手指延伸轴的滚转，本次保持0，`tip_up=-20`保持不变。

```text
R_left  = Rz(+yaw) @ Rx(+20deg) @ R_left_palm_up
R_right = Rz(-yaw) @ Rx(-20deg) @ R_right_palm_up
```

正yaw使两手指尖都往箱+X方向偏，手腕位置略退到箱-X侧。
新版俯视机位中，箱+X在图右、+Y在图上。每个角度重新计算穿孔扫掠截面的居中位置，
保持60 mm法向插入深度；不是把旧位置固定后硬转手腕。

| −20° / −30° | 插入时碰撞、手指限位停止 | 未进入闭合 | — | — |

+20°/+30°虽然插入阶段无手箱接触，但闭合后没有建立持续四指接触，CLOSE门槛拒绝继续抬升。
存在掌部等其他接触力也不能代替指部勾握成功。
推荐先审核**下斜20° + yaw10°**，15°可作为更大偏航备选。
通过的是这些离散角度在同一初始化下的台架动作，不代表连续角域或扰动鲁棒性；
更不证明全身可达、负载平衡或旧Reach策略能执行。
