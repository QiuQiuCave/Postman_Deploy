# 三罐取货桌、远端放货桌与货架场景

本场景只交付场景构建、被动物理验收、图片和可迁移 MJCF；机器人是固定中立姿态参照。
不包含抓取、搬运、行走、规划、状态机或任务成功验证。

## 代码与资源

- 入口：`deploy_mujoco/r2v2_static_task_grid.py`
- 配置：`deploy_mujoco/config/r2v2_static_task_grid.yaml`
- 构建及验收：`common/r2v2_static_task_grid_scene.py`
- 基础场景与资源打包：`common/r2v2_static_task_scene.py`
- 货架：复用 `assets/shelf/shelf.xml`。
  保留源资产不变，构建时合并材质和几何，并给几何名称添加 `shelf_` 前缀。
  源文件注释写 2.70 m，但实际立柱半高 1.05 m，因此实际货架高 2.10 m。

## 默认布局（世界坐标，米）

| 对象 | 位置 | 说明 |
|---|---|---|
| 取货桌 | (0.65, 0.50, 1.09) | 桌板中心，桌面高度 1.11 m |
| 放货桌 | (0.65, -2.50, 1.09) | 初始为空；两桌中心相距 3 m |
| 货架 | (0.65, -3.65, 0) | 固定，绕 Z 旋转 -90°，正面朝 -X |
| 货箱 | (0.65, 0.50, 1.1102) | 外底中心；自由刚体，质量 0.4 kg |
| 三罐阵列中心 | (0.615, 0.50, 1.1754) | 靠近 -X 操作侧 35 mm |

两桌使用相同的 0.39 × 0.52 m 桌面。货架位于放货桌的 -Y 侧，与桌子并排，
最近外轮廓间隙约 0.20 m；两者共同朝向 -X 侧的开放操作区域。
桌子正面 X=0.455，货架正面最外侧 X=0.370。
这只是为后续操作提供空间，不代表已经验证机器人的运动学可达性或行走路线。

货架五层板上表面高度为 0.215、0.635、1.055、1.475、1.895 m；
第三层接近桌面高度。保留原资产前后挡边，放入货物时需要越过挡边。
第三层挡边顶面为 1.075 m；没有预放货物，也没有自动放置逻辑。

## 三个可乐罐

沿 Y 排成一列，世界坐标分别为：

- (0.615, 0.40, 1.1754)
- (0.615, 0.50, 1.1754)
- (0.615, 0.60, 1.1754)

每罐直径 40 mm、高 120 mm、质量 100 g。
罐中心距 100 mm、表面净间隙 60 mm，避免多排遮挡，为手指留出进入空间。
阵列占地 40 × 240 mm，距普通箱壁的最小余量 X=61 mm、Y=56 mm；
计入把手横梁后 Y 方向保守余量为 50 mm。货箱含货总质量 0.7 kg。
箱壁高于罐顶，因此真正抓取仍需后续团队验证伸手方式；本场景没有降低箱壁或改变罐子尺寸。

每罐有独立自由关节、圆柱碰撞体和质量，视觉网格与材质共享。
加上货箱共四个自由刚体，`nq=28, nv=24`；桌子、货架、机器人均固定。
可用 `cargo_grid` 调整行列和间距，也可删除 `shelf` 配置以生成无货架场景。

## 运行

使用 Python 3.10/3.11，从仓库根目录安装轻量依赖并运行：

```bash
uv venv --python 3.11 .venv-r2v2
uv pip install --python .venv-r2v2/bin/python -r requirements-r2v2-static-scene.txt
.venv-r2v2/bin/python deploy_mujoco/r2v2_static_task_grid.py
```

不需要 Torch、ONNX、Ruckig 或机器人 SDK。无窗口渲染默认使用 EGL，
需机器提供相应图形驱动；`--no-render` 仅执行物理验收与导出，不依赖 OpenGL。
`--view` 在验收通过后打开交互查看器；`--config <路径>` 指定其他配置。
默认输出到仓库同级 `tmp/r2v2_static_task/<时间戳>/`，也可用 `--output <新目录>`
指定路径；已有非空输出目录拒绝覆盖。

交付包含 `scene.xml`、`assets/`、`config.yaml`、`layout.json`、`report.json`、
`README.md`、4K `overview.png` 和 1080p `crate_closeup.png`。
货架几何和材质已嵌入导出 XML，不需要额外复制仓库的 `assets/shelf/shelf.xml`。
整个导出目录可以独立复制并用 MuJoCo 3.3.7 加载。

## 验收

默认每次执行两次独立 10 秒试跑，分别加载构建 XML 和导出 XML，比较最终状态，
容差 1e-9。最后 2 秒逐物体验证速度、倾角、漂移和真实支撑力。
每罐约承受 0.981 N，桌面对箱体支撑约 6.867 N。
初始检查包含货架与桌子、货物、机器人及地面的几何关系；
货架自身设计中相接或交叠的立柱、层板和挡边属于同一固定结构，不作为场景穿插错误。
不使用位姿回写或辅助力来维持货物稳定。

```bash
.venv-r2v2/bin/python -m pytest \
  tests/test_r2v2_static_task_grid_scene.py \
  tests/test_r2v2_static_task_scene.py tests/test_r2v2_crate.py -q
```

测试覆盖三罐货架场景的支撑、迁移重载、密集多罐布局，
以及货架与桌子或机器人重叠时拒绝布局的检查。

`deploy_mujoco/config/r2v2_static_task.yaml` 是基础场景模块和测试使用的单罐配置；
运行本场景请使用上述 grid 入口及其默认配置。
