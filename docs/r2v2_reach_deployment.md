## 当前结论

**训练/部署推理对照通过；新整机站立通过；空载搬运终点精度未通过。**
按任务约定停止推进抓取，没有降低验收阈值、替换旧身体或启动训练。
目前实现的是策略适配器、世界目标接口和抓取前置验证状态机，
**不是已经完成的桌面抓取搬运任务**。尚未接入实体台面/圆柱、接触抓握判定、
带物搬运、落放释放及连续三次成功验收，也未改动 G1 或 `FSM/R2V2FSM.py` 入口。

现有固定手腕 75° 抓取基线和轨迹保持不变，见
[抓取 FSM 交接记录](r2v2_grasp_fsm_handoff.md)。

## 运行

以下命令在本仓库根目录执行。部署环境是 Python 3.11 的 `.venv-r2v2`；
数值对照另外调用相邻 `AMO_R2/.venv/bin/python` 中已配置的训练环境，
不会在部署环境安装 Torch，也不会修改训练仓库或其依赖。

```bash
uv pip install --python .venv-r2v2/bin/python -r requirements-r2v2-reach-sim.txt
.venv-r2v2/bin/python -m pytest -q tests

# 原训练模型的两个真实 rollout，共 240 帧，包含历史滚动、目标切换和 reset。
.venv-r2v2/bin/python tools/verify_r2v2_reach_policy.py

# 只有数值对照报告与当前权重/适配器 SHA-256 一致才允许启动。
.venv-r2v2/bin/python deploy_mujoco/r2v2_reach_validate.py \
  --parity-report artifacts/r2v2_reach/parity_12000/report.json \
  --video
```

默认验证输出为 `artifacts/r2v2_reach/时间戳/`；可用 `--output` 指定空目录，
不允许覆盖非空目录。没有显示器时自动使用 EGL。
兼容性通过返回退出码 0，门槛未通过返回 1；本次的退出码 1 是明确的验收失败，
并非脚本崩溃。若只重做部署数值比较，可在已有原生快照上执行
`tools/verify_r2v2_reach_policy.py --reuse-snapshots`。

默认模型为训练目录
`logs/rsl_rl/r2v2_reach_dual_arm_speed_limited_28dof/2026-08-30_00-45-04_dual-arm-speed-limited-v1-from-13250/`
下的 `model_12000.pt` 和同目录同名 ONNX。它们不复制进 Git。
更换机器后修改 YAML 的两个权重路径，并在对照工具中对应传入
`--training-root`、`--checkpoint`、`--onnx`。
相对权重路径始终相对于本仓库根目录解析。

## 策略与控制约定

- 输入 `float32[1,1460]`，输出 28 维动作。单步 146 维、24 个观测项；
  **每个观测项各自保留 10 帧、从旧到新，再按项拼接**，不是直接堆叠 10 个完整单步向量。
  reset 时用首帧填满历史。归一化已经包含在 ONNX 中，不重复归一化。
- 默认关节角和 PD 参数读取并校验训练定义；目标关节角为 `q_default + 0.25 * action`。
  身体策略不观察也不输出手指关节；身体与手部控制器不会覆盖对方通道。
- 身体策略 50 Hz，手指轨迹 100 Hz，MuJoCo 接触仿真与两组限力矩 PD 均为 1 kHz。
  保留训练速度条件：线速度 0.25 m/s、角速度 0.8 rad/s，
  参考加速度 0.8 m/s² 和 2 rad/s²。这是参考轨迹约束，不是实际手腕速度的硬约束。
- 零行走指令，身体高度/俯仰条件 `[0.82, 0]`。初始化跟随当前双手参考 0.4 s，
  再进入待机位姿；站稳后锁定右手世界目标，不锁死其肩肘关节。
- 新身体保留真实关节限位、惯量、碰撞、摩擦和关节动力学。
  仅增加无质量的虚拟 TCP site 和设置 1 ms 仿真步长。
  根据新脚底 28 个碰撞球在 reset 时一次性调整根高度，初始离地间隙 1 mm，
  本次根高度为 0.817151613 m；运行中没有焊接、外力支撑或位姿重置。

### 世界目标与物体坐标

`ReachPolicy.set_target_world(side, position, quaternion)` 接收
**虚拟 TCP 的世界位置（m）和世界姿态（wxyz）**。仅更新终点，保留参考当前状态；
目标应在每段进入时设置，不逐帧重新初始化轨迹。
调试 YAML 的待机位置用进入待机时的本体 yaw 坐标，后三项是角度制 RPY，
按 `Rz(yaw) @ Ry(pitch) @ Rx(roll)` 转换后，内部使用四元数。

手腕是 `left_hand_roll_link` / `right_hand_roll_link`。
兼容旧策略的虚拟 TCP 相对手腕平移分别为
`[0.1735, -0.0000004, -0.0317504]` 和
`[0.1735, +0.0000004, -0.0317504]` m，旋转为单位四元数。
该固定变换由训练模型 FK 得到，**不表示新手掌中心，也不能消除新旧身体运动学差异**。

左手使用已归档关系 `T_wrist_cylinder`：平移 `[0.145, -0.035, 0]` m，单位旋转。
空载目标依次按以下关系计算：

```python
T_world_wrist = T_world_cylinder @ np.linalg.inv(T_wrist_cylinder)
T_world_tcp = T_world_wrist @ T_wrist_tcp
policy.set_target_world("left", T_world_tcp[:3, 3], tcp_quaternion_wxyz)
```

当前 `T_world_cylinder` 是用来预验收的**假想物体位姿**，场景中没有物体。
后续实体任务必须改为仿真真值；放置姿态必须使用抓稳后实测的手腕—圆柱关系重算。
到位和右手保持验收均检查**物理手腕**，避免虚拟 TCP 误差较小掩盖腕部误差。

## 2026-09-07 验证结果

数值对照报告：`artifacts/r2v2_reach/parity_12000/report.json`。
ONNX 权重、归一化参数与 checkpoint 对应一致；240 帧原生训练快照中：

| 对照项 | 最大绝对误差 | 门槛 |
| --- | ---: | ---: |
| 部署观测及历史 vs 原训练观测 | 3.58e-7 | 5e-5 |
| 同一原生观测的 ONNX vs 训练网络动作 | 3.34e-6 | 1e-4 |
| 部署重建观测后输出 vs 原训练动作 | 1.41e-5 | 2e-4 |

新整机最终复验目录：`artifacts/r2v2_reach/new_model_gate_release/`。
从初始化到失败的完整视频约 36.5 s，包含全身与手臂两个视角。

| 阶段 | 进入时间 / s | 结果 |
| --- | ---: | --- |
| 初始跟随 | 0.00 | 完成 |
| 待机 Reach | 0.40 | 完成 |
| 自由站立 | 2.18 | 连续 20 s 通过 |
| 空载预接近 | 22.18 | 通过 |
| 空载抓取位姿 | 23.42 | 通过 |
| 空载抬升 8 cm | 24.90 | 通过 |
| 向中线平移 10 cm | 26.40 | 未通过，36.40 s 超时停止 |
| 空载落放 | — | 未执行 |

前三个空载运动终点均满足腕部位置 <5 mm、姿态 <3°、速度 <2 cm/s，
且真实经过时间持续达标至少 0.3 s。平移终点的最终指标：

| 指标 | 实测值 | 要求 |
| --- | ---: | ---: |
| 左腕位置误差 | **6.30 mm** | <5 mm |
| 左腕姿态误差 | **4.06°** | <3° |
| 左腕线速度 | 0.155 mm/s | <20 mm/s |
| 右腕锁定后最大位置误差 | 14.30 mm | <20 mm |
| 右腕锁定后最大姿态误差 | 2.78° | <5° |
| 整段最大身体倾斜 | 2.56° | <35° 安全停止阈值 |

身体实际关节越界峰值 0，身体力矩饱和比例 0，无非脚部着地、跌倒或数值警告。
最大机器人自接触深度 0.218 mm；脚底软接触的地面穿透单独记录，
不能与机器人自接触指标混为一谈。没有修改新模型接触参数来改善结果。

终点已基本停稳，因此失败不是等待时间不足造成的明显瞬态误差。
接口对照通过并不代表跨模型端点精度通过；新模型的手腕相对旧模型约降低
107.47 mm，部分肘/腕限位、脚底接触和惯量也不同。
**当前结果不能单独证明误差只来自某一种模型差异，也不能据此断言必须重新训练。**

### 输出与证据范围

- `report.json`：完整配置、模型维度/质量、策略及代码校验值、状态切换、各阶段退出误差、失败阶段、右手误差峰值及安全指标。
- `trace.json`：100 Hz 双手目标/参考/实测位姿、腕部误差与速度、身体关节/动作/力矩、接触对及穿透；状态切换时同步记录。
- `compatibility.mp4`、`initial.png`、`final.png`：全过程双视角视频和首尾截图。

日志同时保留虚拟 TCP 的 `position_m` 与物理手腕的 `wrist_position_m`，
不要用前者替代抓取到位指标。接触记录对应刚结束的物理步，运动学使用独立
`MjData` 对当前 qpos/qvel 做 FK，不改写在线物理状态。
尚无实体圆柱，因此本轮没有物体轨迹、抓握接触力/滑移、触台释放或三次成功率数据。
这不是缺省为通过，而是明确未执行。大体积日志/视频位于忽略的 `artifacts/`，不随 Git 保存。

自动化测试共 72 项通过，覆盖原有手部基线、观测历史与动作映射、独立身体/手部通道、
坐标转换、数值对照工具、新模型参数保留、足底初始化、真实持续时间、腕部门槛，
以及两个记录时刻之间触发安全停止时的日志时间同步。

## 继续开发的前提

先处理或定位这个空载稳态误差，再以相同门槛重验整套目标。
可以另行讨论局部目标补偿/标定及原训练模型在相同目标下的基线对照；
未经授权不自动补偿目标、不换模型，也不启动微调训练。
兼容性通过后再接实体台面/圆柱及完整抓取状态机，并继续保留固定手腕基线。
尤其不能将手部控制器的 `CLOSED` 当作真实抓握成功，
也不能在搬运失败时自动空中松手。
